# Cotali — Identidade visual

**Status:** oficial  
**Versão:** 0.1  
**Data:** 2026-09-03

## Paleta oficial

| Cor         | Código HEX | Uso principal                                                |
| ----------- | ---------- | ------------------------------------------------------------ |
| Azul Cotali | `#1846e1`  | Cor primária da marca, ações, links e elementos de destaque. |
| Branco      | `#ffffff`  | Fundo, texto sobre o azul e áreas de contraste.              |

Essas duas cores formam a paleta base do Cotali. Novas cores de apoio só devem ser adicionadas quando houver uma necessidade de produto ou acessibilidade documentada.

## Regra de aplicação

- Usar `#1846e1` como azul primário da interface e da comunicação da marca.
- Usar `#ffffff` para garantir contraste em textos e componentes sobre o azul.
- Manter os códigos em minúsculas e sem alterar os valores hexadecimais oficiais.
