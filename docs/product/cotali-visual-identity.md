# Cotali — Identidade visual

**Status:** oficial  
**Versão:** 0.1  
**Data:** 2026-09-03

## Paleta oficial

| Cor         | Código HEX | Uso principal                                                |
| ----------- | ---------- | ------------------------------------------------------------ |
| Azul Cotali | `#1846e1`  | Cor primária da marca, ações, links e elementos de destaque. |
| Branco      | `#ffffff`  | Fundo, texto sobre o azul e áreas de contraste.              |

Essas duas cores formam a paleta base do Cotali. Novas cores de apoio só devem ser adicionadas quando houver uma necessidade de produto ou acessibilidade documentada.

## Cores de apoio para o site público

Para a landing page, foi aprovada uma extensão controlada da paleta base para criar profundidade, hierarquia e contraste entre superfícies. Essas cores não substituem o Azul Cotali e não devem virar uma paleta multicolorida.

| Cor           | Código HEX | Uso principal                                               |
| ------------- | ---------- | ----------------------------------------------------------- |
| Azul profundo | `#102c87`  | Superfícies de apoio e estados de maior profundidade.       |
| Quase preto   | `#0b1220`  | Texto forte, fundos escuros e áreas de produto.             |
| Cinza nuvem   | `#f5f7fb`  | Fundos alternados e agrupamento visual de seções.           |
| Cinza névoa   | `#e6ebf3`  | Bordas, divisores e superfícies discretas.                  |
| Azul claro    | `#dfe8ff`  | Destaques suaves e áreas de apoio sem competir com a marca. |
| Cinza ardósia | `#60708d`  | Texto secundário e metainformação com contraste controlado. |

O site deve preservar o Azul Cotali (`#1846e1`) como ação e destaque principal. O quase preto, os cinzas e os azuis auxiliares devem apoiar a leitura e a demonstração do produto, seguindo uma aplicação próxima à referência visual da Cruip.

## Regra de aplicação

- Usar `#1846e1` como azul primário da interface e da comunicação da marca.
- Usar `#ffffff` para garantir contraste em textos e componentes sobre o azul.
- Manter os códigos em minúsculas e sem alterar os valores hexadecimais oficiais.
